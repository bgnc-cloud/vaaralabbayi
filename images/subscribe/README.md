# Subscribe page images (`subscribe.html`)

Drop photos into this folder using **exactly** these file names.

## Rules

- Format: **JPG only** (`.jpg`, lowercase extension). File names are case-sensitive on the live server.
- Size: **under 150 KB** per file; the background `preregister-bg.jpg` **under 200 KB**.
- Use the exact pixel size below. The photos are shown whole (not cropped or stretched); the background `preregister-bg.jpg` fills its section and may lose a little at the edges.
- **No text inside the pictures**: words in a photo cannot switch to Telugu. Put text in the page instead.
- Use photos you own or are licensed to use.
- If a file is missing, its slot removes itself and the page looks exactly as it does without photos.

## Alt text

English and Telugu alt text is written in `subscribe.html` for each photo (`alt`, `data-alt-en`, `data-alt-te`).
If you replace a photo with a different scene, update those three attributes too.
